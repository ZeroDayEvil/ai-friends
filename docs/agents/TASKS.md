## Что нужно от владельца инфраструктуры

Эти пункты нельзя закрыть агентами, они требуют ваших действий:

1. Создать приватный репозиторий на GitHub и дать доступ (или установить
   `gh` и авторизоваться) — после этого локальная история будет запушена и
   станут доступны облачные агенты.
2. Выдать Linux VPS (Ubuntu 24.04) с root-доступом по SSH-ключу.
3. Подключить домен к Cloudflare и создать API-токен с правами на Tunnel и Access.
4. Для матрицы совместимости — машины Win10, Win11, Server 2016/2019/2022.
