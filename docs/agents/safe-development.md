# Безопасная работа агентов

Обязательные машинно-читаемые инструкции находятся в
`.github/copilot-instructions.md`. Этот документ объясняет порядок работы.

## Граница исполнения

До перевода `security/build-approval.json` в проверенное состояние `approved`
агентам разрешены только операции над недоверенным кодом как над данными:

- чтение и поиск;
- вычисление хешей;
- проверка списка и типа файлов;
- безопасный разбор манифестов и архивов;
- написание отчётов, политик и собственных тестовых fixtures.

Запрещены установка пакетов, lifecycle-скрипты, импорт модулей из исследуемого
дерева, build/test-команды upstream и запуск скачанных бинарников. Само наличие
lock-файла не является разрешением: он фиксирует полученные байты, но не
доказывает безопасность их содержимого.

## Переход к сборке

Оркестратор открывает gate только отдельным reviewable-изменением после того,
как одновременно выполнены условия:

1. upstream закреплён commit и file hashes;
2. npm-доставляемый браузерный клиент сопоставлен с исходником и проверен;
3. production dependency graph имеет официальный источник, точную версию,
   integrity, лицензию и verdict для каждого компонента;
4. lifecycle/native-компоненты собраны или допущены по явной политике;
5. удалены или исправлены подтверждённые RCE, XSS, arbitrary file access, SSRF
   и shell injection;
6. независимый security-review не оставил необработанных critical/high
   замечаний.

Approval привязывается к конкретным хешам source, dependency и native
манифестов. Любое изменение этих хешей автоматически закрывает gate.

## Разделение работы

Одна сессия соответствует одной ветке и одному PR. Независимые статические
аудиты выполняются параллельно; изменения identity, execution boundary,
AI/MCP control plane и browser worker идут последовательно после заморозки
контрактов. Автор изменения не выполняет его финальный security-review.

Cloud-agent получает только минимальную среду для чтения репозитория и запуска
собственной проверки политики. Он не устанавливает зависимости приложения
автоматически.
