# Cloudflare Tunnel и Zero Trust Access

## Что это даёт

Туннель устанавливает исходящее соединение от узла к Cloudflare, поэтому на
сервере не нужно открывать ни одного входящего порта. Публично адресуемым
становится только имя в вашей зоне, а сам узел остаётся невидимым для сканеров.

Access добавляет проверку личности до того, как запрос дойдёт до приложения.
Это закрывает главный пробел стокового electerm-web: в нём один общий пароль на
всех, без учётных записей и журнала. С Access у каждого сотрудника свой вход с
MFA, а отзыв доступа делается в одном месте.

## Порядок настройки

1. Домен переносится в зону Cloudflare, DNS обслуживается Cloudflare.
2. В Zero Trust создаётся туннель, его идентификатор и файл учётных данных
   кладутся на узел в `/etc/cloudflared/`.
3. `config.yml` берётся из `config.sample.yml`, подставляются `tunnel` и имя хоста.
4. Служба включается: `cloudflared service install`, затем
   `systemctl enable --now cloudflared`.
5. В Zero Trust создаётся приложение типа Self-hosted на то же имя хоста и
   политика доступа: разрешить конкретные адреса электронной почты или группу,
   обязательный второй фактор.
6. Из настроек приложения берутся `AUD` и `team domain` и прописываются в `.env`
   узла как `CF_ACCESS_AUD` и `CF_ACCESS_TEAM_DOMAIN`.

## Почему приложение обязано проверять JWT само

Access ставит подписанный JWT в заголовок `Cf-Access-Jwt-Assertion`. Если
приложение его не проверяет, а просто доверяет тому, что «мы за туннелем», то
любой, кто сумеет обратиться к порту приложения напрямую (изнутри узла, из
контейнера, через ошибку в конфиге туннеля), получит полный доступ без входа.
Поэтому проверка подписи по публичным ключам
`https://<team>.cloudflareaccess.com/cdn-cgi/access/certs` и сверка `aud`
делается в самом приложении. Это же даёт нам имя пользователя для прав доступа
внутри платформы.

## Что не покрывает Access

Access защищает HTTP. Прямые RDP, SSH и VNC к целевым машинам он не закрывает --
для них нужен меш WireGuard, а на самих машинах доступ ограничивается подсетью
меша.
