# electerm-platform

Инфраструктура и сборка командной платформы удалённого доступа на базе форка
[electerm-web](https://github.com/electerm/electerm-web) (MIT).

## Главное правило

Ни один агент и ни один человек не меняет серверы вручную. Всё, что попадает на
серверы, лежит в этом репозитории в виде скриптов и конфигов и применяется их
запуском. Проверка «сделана ли задача» — это чтение диффа, а не доверие отчёту.

Из этого следуют два практических требования:

- любая настройка сервера, сделанная руками, считается утраченной и должна быть
  перенесена в `infra/` до следующего развёртывания;
- секреты в репозиторий не попадают: только файлы `*.sample` с описанием
  переменных.

## Структура

    infra/vps/        развёртывание Linux-узла: Docker, наш образ, cloudflared, WireGuard
    infra/windows/    подготовка Windows-целей: OpenSSH, хардненинг, RDS
    infra/wireguard/  выдача ключей и конфиги узлов меша
    infra/cloudflare/ туннель и политика доступа как конфиг
    docs/agents/      роли агентов, брифы, реестр задач
    docs/audit/       отчёты по цепочке поставок
    docs/design/      архитектурные решения
    security/         реестр внешних зависимостей с пинами
    scripts/          вспомогательные утилиты оркестрации

## Состояние окружений

| Узел | Роль | Доступ |
|---|---|---|
| GCP Windows Server 2025 (`35.208.225.47`) | тестовая цель | SSH по ключу (`ssh winsrv`), RDP |
| Linux VPS | web-узел, cloudflared, WireGuard | не создан |
| Домен + Cloudflare | публичная дверь | не подключён |

Подробности по Windows-цели: [docs/design/environments.md](docs/design/environments.md).

## С чего начать

1. Прочитать [docs/agents/README.md](docs/agents/README.md) — как распределены роли.
2. Посмотреть текущие задачи в [docs/agents/TASKS.md](docs/agents/TASKS.md).
3. Перед изменением зависимостей — [security/README.md](security/README.md).

## Лицензии

Форк electerm-web распространяется под MIT, что позволяет закрытое использование
и модификацию. Сторонние наработки, из которых берутся подходы, имеют разные
лицензии: `websockify` — LGPL-3.0, `goproxy` — GPL-3.0. Копирование их кода в
наш продукт недопустимо без анализа совместимости лицензий; используются только
идеи и протоколы, а не исходники.
